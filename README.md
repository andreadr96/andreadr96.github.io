# Andrea Doña - Portfolio Web 🌸

¡Bienvenido/a al repositorio de mi portafolio personal! 

Este proyecto es la carta de presentación de mi perfil profesional, diseñado para destacar mi experiencia y habilidades duales: por un lado, como **Level Designer & Artista 3D**, y por otro, como **Game Producer / Project Manager**, todo ello sustentado por mi formación en **Psicología**.

🔗 **[Ver el Portafolio en Vivo](https://andreadr96.github.io)** *(Asegúrate de tener GitHub Pages activado en tu repositorio)*

## ✨ Características del Proyecto

- **Navegación Dinámica:** Desarrollado como una "Single Page Application" (SPA) utilizando Vanilla JavaScript puro para lograr transiciones fluidas sin necesidad de recargar la página.
- **Diseño Moderno:** Estética limpia y minimalista, implementando técnicas de *Glassmorphism* y una paleta de colores suaves (blancos y acentos de flor de cerezo/Sakura) para un aspecto muy profesional y atractivo.
- **Responsive Design:** Completamente adaptable a diferentes tamaños de pantalla (móviles, tablets y escritorio).
- **Bifurcación de Perfiles:** Interfaz intuitiva que permite al visitante explorar el contenido más relevante según su interés (Diseño/Arte o Gestión/Producción), reflejando la versatilidad de mi perfil.

## 🛠️ Tecnologías Utilizadas

Este portafolio ha sido construido desde cero, sin frameworks pesados, para garantizar un rendimiento óptimo, carga rápida y demostración de fundamentos sólidos:

- **HTML5:** Código semántico y estructurado.
- **CSS3:** Variables CSS, Flexbox, CSS Grid y animaciones personalizadas (efecto cristal o Glassmorphism).
- **Vanilla JavaScript:** Lógica para la navegación, manejo de eventos del DOM e interactividad.
- **FontAwesome:** Para la iconografía de las diferentes secciones.
- **Google Fonts:** Tipografía principal ('Outfit') para una lectura amigable y moderna.

## 🚀 Cómo visualizar el proyecto en local

Si deseas clonar o descargar este repositorio para visualizarlo en tu equipo local, el proceso es inmediato (no requiere instalación de dependencias ni servidores como Node.js):

1. Clona el repositorio:
   ```bash
   git clone https://github.com/andreadr96/andreadr96.github.io.git
   ```
2. Abre la carpeta del proyecto en tu explorador de archivos.
3. Haz doble clic en el archivo `index.html` para abrirlo directamente en tu navegador predeterminado (Chrome, Firefox, Safari, Edge, etc.).
